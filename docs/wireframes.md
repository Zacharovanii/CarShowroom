# Макеты экранов

Каркасы всех страниц из [use-cases.md](use-cases.md) с состояниями: загрузка, пусто,
ошибка, гость против вошедшего. Значения отступов и цветов — в
[design-system.md](design-system.md), живые компоненты — в [styleguide.html](styleguide.html).

Обозначения: `[Кнопка]` — первичная, `(Кнопка)` — вторичная, `‹Кнопка›` — призрачная,
`▓` — фото, `░` — затемнение поверх фото, `▪▪▪` — скелетон, `●` — выбранный элемент.

Статус: **черновик 1** (23.09.2026).

---

### Карточка автомобиля

```
┌────────────────────────────────────────────────────────────────────────┐
│ ┌────────────────────────┐                                             │
│ │ [3D] [Электро]         │  ← бейджи с иконками                        │
│ │                        │                                             │
│ │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓     │  ← карточка 3:4, вертикальная               │
│ │   ▓▓▓▓▓  фото  ▓▓▓▓    │  ← фото тянется по высоте                   │
│ │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓     │  ← и подрезается по бокам                   │
│ │                        │                                             │
│ │ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │  ← блюр поднимается снизу вверх             │
│ │ ░░░░░░░░░░░░░░░░░░░░░░ │  ← затемнение 96% поверх блюра              │
│ │ BMW 320i          2026 │                                             │
│ │ 4 650 000 ₽            │                                             │
│ │                        │                                             │
│ │ 184     задний  бензин │                                             │
│ │ Л.С.    ПРИВОД  ДВИГ.  │                                             │
│ │                        │                                             │
│ │                ┌─────┐ │  ← кнопка отдельной строкой:                │
│ │                │  →  │ │  ← ничего не перекрывает                    │
│ │                └─────┘ │  ← hover: [ →  Смотреть ]                   │
│ └────────────────────────┘                                             │
└────────────────────────────────────────────────────────────────────────┘
```

Полоса характеристик — три поля, которые есть в `carCardSchema`: мощность, привод,
тип двигателя. Разгона и максималки в каталоге нет, они приходят только на странице
автомобиля, и расширять ради них контракт не стали (D23).

Затемнение под текстом — два слоя. Снизу вверх поднимается размытие, маска гасит его
к верху кадра; поверх лежит затемнение до 96% плотности поверхности. Контраст держит
именно второй слой: размытое белое остаётся белым, и на светлом кузове один блюр
текст бы не вытянул. Плотность посчитана по худшему случаю — белому кузову прямо
под подписью: основной текст 14.2:1, подпись капсом 5.0:1.

Кнопка стоит отдельной строкой под характеристиками. В углу поверх них она
перекрывала бы третье поле, а на узкой вертикальной карточке это как раз
тип двигателя.

Слот несёт три состояния из `slotSchema`, и ни одно не передаётся только цветом:

| Состояние | Данные | Вид |
| --- | --- | --- |
| свободен | `free && bookable` | граница `--color-border-control`, кликабелен |
| занят | `!free` | заливка `--color-surface`, подпись зачёркнута, `aria-disabled` |
| недоступен | `free && !bookable` | текст `--color-fg-disabled`, подпись «рано» |
| выбран | локальное состояние | заливка `--color-accent-solid`, `aria-pressed` |

Слот «недоступен» — это правило TD-5 (ближе чем через 2 часа). Считает сервер,
фронт правило не повторяет.

в кнопку отсчёт не помещается на 375). 429 → «Слишком много попыток, попробуйте через
минуту.»

- после регистрации форма сменяется экраном «Проверьте почту»: «Мы отправили письмо
  на {email}… Ссылка действует 1 час», «Отправить ещё раз» (сразу на паузе — письмо
  только что ушло), внизу «Подтвердили email? Войти →»;
- вход неподтверждённым — над формой предупреждение «Email не подтверждён. Мы
  отправили новое письмо на {email}…» и «Отправить письмо ещё раз» (тоже сразу
  на паузе);
- `/verify-email` — «Подтверждаем email…» со спиннером, затем: успех → тост «Email
  подтверждён» и кабинет; повторный переход гостя → «Email подтверждён. Теперь войдите
  с email и паролем.» + «Войти»; ошибка → «Ссылка устарела» / «Ссылка недействительна»,
  поле email и «Выслать письмо заново», внизу «Уже подтвердили email? Войти →»;
- `/forgot-password` — «Восстановление пароля», поле email, «Отправить ссылку»; после
  отправки всегда «Проверьте почту»: «Если такой адрес зарегистрирован, мы отправили…»;
- `/reset-password` — «Новый пароль», пароль и подтверждение, «Сохранить пароль» →
  «Пароль изменён» + «Войти»; плохая ссылка → «Ссылка недействительна» + «Запросить
  новую». Внизу обеих страниц — «← Вернуться ко входу».

Сами письма (`apps/api/src/mail/templates.ts`) — таблица с инлайн-стилями: приветствие
по имени, абзац, кнопка («Подтвердить email» / «Задать новый пароль»), та же ссылка
текстом, «Ссылка действует 1 час. Если это были не вы — просто проигнорируйте письмо.»

таблица — карточки: обложка, название, «серия · год», цена, бейджи.

```
┌────────────────────────────────────────────────────────────────────────┐

│  ▣ m4.glb  /media/models/5/…glb   Материал краски: CarPaint            │
│                                                  (Удалить модель)      │
│  Заменить модель: GLB-файл [Обзор…]  Материал краски [CarPaint__]      │
```

**Новый автомобиль** `/admin/cars/new` — заголовок «Новый автомобиль», подпись
«Сохранится черновиком…», только секция «Карточка» и кнопка [Создать]. После успеха —
тост «Черновик создан» и переход на `/admin/cars/:id`: фото и модель привязываются к `id`.

**Шапка карточки:** у черновика — [Опубликовать] вместо «Снять с публикации», ссылки
на сайт нет. Без фото публикация отклоняется (`CAR_NOT_READY`), под кнопками —
пометка «Чтобы опубликовать, загрузите хотя бы одно фото». «Удалить» → диалог «Удалить автомобиль?»;
при записях на тест-драйв — диалог «Удалить нельзя» с [Снять с публикации]
(у черновика — [Понятно]).

**Фото:** выбранные файлы уходят по одному, очередь показывает «ожидает / загружается /
готово» или ошибку у файла. Удаление — диалог «Удалить фото?». **3D:** без модели —
«3D-модели нет…» и форма «Загрузить модель»; материала нет в файле
(`PAINT_MATERIAL_NOT_FOUND`) — под полем чипы с именами материалов модели. Удаление —
диалог «Удалить 3D-модель?».

Загрузка — скелетон формы; нет автомобиля — «Автомобиль не найден» и [К списку
автомобилей]; ошибка — «Не удалось загрузить автомобиль» и [Повторить]. На телефоне
секции и поля идут в одну колонку.

## 11. Сводка состояний

Проверочная таблица: у каждого экрана с данными должны быть все четыре.

| Экран | Загрузка | Пусто | Ошибка | Роль меняет вид |
| --- | --- | --- | --- | --- |
| Главная | скелетоны карточек | — | секция скрывается | шапка |

| Автомобиль | скелетон галереи и характеристик | — | «Автомобиль не найден» | блок тест-драйва |

| Кабинет | скелетон формы | — | плашка над кнопками | только клиент |
