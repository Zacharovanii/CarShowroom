# Выжимка ТЗ

Источник: «Длительная практическая работа (проект). Разработка многостраничного веб-сайта
на React с маршрутизацией (React Router DOM), регистрацией и авторизацией», МДК 01.06,
09.02.07, 4 курс. Срок — около двух недель.

## Чек-лист и где закрывается

| Требование                                                                       | Где у нас                                                                                                         |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 5–6+ маршрутов: главная, каталог, элемент `:id`, вход, регистрация, кабинет, 404 | см. карту маршрутов в design-plan                                                                                 |
| `BrowserRouter`/`Routes`/`Route`                                                 | декларативный режим React Router                                                                                  |
| Вложенный маршрут через `<Outlet />`                                             | `/account/*` (контакты, мои записи)                                                                               |
| `useParams`                                                                      | `/catalog/:slug`                                                                                                  |
| `useNavigate`                                                                    | переход в кабинет после входа/регистрации                                                                         |
| Protected Route                                                                  | обёртка над `/account`                                                                                            |
| NavLink с активным пунктом                                                       | `Header`                                                                                                          |
| 404                                                                              | `path="*"`                                                                                                        |
| 8–10 функциональных компонентов, `components/` и `pages/`                        | структура `apps/web/src`                                                                                          |
| 2–3 переиспользуемых компонента                                                  | `components/ui/*`, `CarCard`                                                                                      |
| `useState` в 5+ компонентах, `useEffect` в 2+ сценариях                          | фильтры, выбор цвета, формы, модалки, выбор слота; синхронизация фильтров с URL, выбор цвета → материал 3D-модели |
| Пропсы в 3+ местах, колбэки в 2+                                                 | `CarCard`, `ColorPicker`, `SlotPicker`, `Filters`                                                                 |
| Context API                                                                      | `AuthContext` (обёртка над сессией Better Auth), тема                                                             |
| Регистрация: имя, email, пароль, подтверждение, клиентская валидация             | zod-схема формы из contracts                                                                                      |
| Вход с ошибкой при неверных данных, logout, F5 сохраняет сессию                  | Better Auth (cookie-сессия)                                                                                       |
| Шапка зависит от статуса                                                         | `Header`                                                                                                          |
| Список через `.map()` с `key`, фильтр/поиск, условный рендеринг в 2+ местах      | каталог, пустые состояния, скелетоны                                                                              |
| 2+ анимации, адаптив, единый стиль                                               | токены motion, дизайн-система                                                                                     |
| Только `let/const`, чистая консоль, комментарии в нетривиальных местах           | ESLint                                                                                                            |
